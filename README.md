## 🔥 The Core Idea
**By 2050, people won’t "visit hospitals" frequently — hospitals will access your health timeline.**

**Living Health DNA (LHD)** is a decentralized, patient-owned health ledger. It replaces static medical reports with an AI-driven, continuously analyzing living digital twin of your health. Web3 ensures complete ownership, privacy, and consent logic. 

Instead of waiting for diagnosis, LHD focuses on **prediction** and **early anomaly detection**.

---

## 💡 How It Works
### 🧠 AI Layer
Our continuous health intelligence system builds a baseline of your body based on vitals, sleep, metabolism, and mental state. By detecting micro-deviations years before symptoms appear, the system flags proactive insights (e.g., *"Your inflammation trend since 2028 suggests early autoimmune risk by 2034."*).

### 🔗 Web3 Layer (Decentralized & Patient-Owned)
Data is stored as encrypted fragments on-chain. **You remain in complete control** of who sees what, and for how long. Doctors and specialists are granted temporary access NFTs rather than permanent copies of your most sensitive health records.

---

## 🌟 Key Platform Features

### 1️⃣ Multi-Agent AI System
The core engine consists of specialized AI agents working constantly in the background. The UI visibly illustrates which agents generated an insight:
- **Baseline Agent**: Constantly maps your normal biological profile.
- **Anomaly Detection Agent**: Flags deviations from your personal baseline.
- **Risk Prediction Agent**: Forecasts future health scenarios.
- **Explanation Agent**: Simplifies complex data into clear, accessible language.
- **Compliance Agent**: Ensures outputs adhere strictly to medical safety guardrails.

### 2️⃣ Explainable AI & Transparency
Every prediction generated by the platform includes:
- **"Why this insight was generated"**: Expands to show the exact data sources and patterns used.
- **Confidence & Risk Scores**: Clearly displayed probability scores using soft, medical-grade color gradients (rejecting alarming red flashes).

### 3️⃣ Safe Medical Guardrails & Human-in-the-loop
The platform is an assistant, **not a replacement for doctors**.
- **No Diagnoses**: You will never see definitive warnings like *"You will get X disease"*. Instead, outputs focus on patterns: *"Pattern suggests increased risk."*
- **Doctor Access Flow**: When the UI detects high-risk parameters, it triggers an immediate Call-To-Action (CTA) prompting you to securely share temporary access with a medical specialist.

### 4️⃣ Immutable Health Activity Log
Every interaction with your Living Health DNA is logged on an auditable, DNA-strand timeline.
- Track who viewed your data.
- Track exact timestamps of access grants and revocations.
- View transparent logs of internal AI decision checkpoints.

## 🎨 Design & UX Philosophy
We reject the standard cyberpunk or hacker visual tropes. LHD is designed with a **calm, medical-grade, premium feel**. The interfaces are organic, biological, and human-centered—inspired by DNA, cellular geometry, and systemic flow, ensuring the user feels a deep sense of trust and safety.

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+) and `npm` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hrshwniii/living-health-ai.git
   cd living-health-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open the App:** Navigate to `http://localhost:8080` in your browser.

### Build for Production
To build the application for production deployment:
```bash
npm run build
```
